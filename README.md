# UN7KAI Radio

Начальная версия Android-приложения для выбора радиолюбительских диапазонов и перехода к интернет-SDR.

## Сборка APK
GitHub Actions запускает `gradle assembleDebug` после загрузки файлов в ветку `main`.
Готовый APK появится в разделе Actions в артефакте `UN7KAI-Radio-APK`.

## Важно
Приложение не содержит физического радиоприёмника. Оно открывает удалённые SDR-сервисы в браузере.
Доступность 2 м, 70 см и спутникового приёма зависит от наличия подходящего удалённого приёмника.
